## Задача

Все обязательные пункты технического задания выполнены.

# Именование

### Б3. Имена в `camelCase`

Названия переменных, параметров, свойств и методов:

* начинаются со строчной буквы;
* записываются в нотации `camelCase`.

```js
// Плохо
const user_name = 'Alex';

// Хорошо
const userName = 'Alex';
```

---

### Б4. Используются английские существительные

Для названия значений используются английские существительные.

Допустимые сокращения:

* `evt` — события;
* `i`, `j`, `k` — счетчики циклов;
* `cb` — callback;
* `img` — изображение;
* `src` — адрес ресурса;
* `err` — ошибка.

Булевы значения и предикаты можно именовать через `is`.

```js
const isLoading = true;

function isNull(value) {
  return value === null;
}
```

---

### Б5. Константы в `UPPER_SNAKE_CASE`

Постоянные значения записываются заглавными буквами через подчеркивание.

```js
const MAX_HEIGHT = 400;
const EARTH_RADIUS = 6370;
```

---

### Б6. Имена классов

Классы:

* названы английскими существительными;
* начинаются с заглавной буквы.

```js
class Wizard {}
class Runner {}
```

---

### Б7. Перечисления (`Enum`)

Перечисления:

* названы существительными в единственном числе;
* начинаются с заглавной буквы;
* значения перечислений оформлены как константы.

```js
const View = {
  ARTIST: 'Artist',
  GENRE: 'Genre',
};
```

---

### Б8. Имена массивов — во множественном числе

```js
const users = [];
const names = [];
const friends = [];
```

---

### Б9. В имени нет типа данных

```js
// Плохо
const filtersArray = [];
const wizardObject = {};

// Хорошо
const filters = [];
const wizard = {};
```

---

### Б10. Название функции содержит глагол

```js
// Плохо
const randomNumber = () => Math.random();

// Хорошо
const getRandomNumber = () => Math.random();
```

---

### Б11. Имена файлов модулей

Файлы модулей:

* записываются строчными буквами;
* слова разделяются дефисами.

```text
game-view.js
user-card.js
api-service.js
```

# Форматирование и внешний вид

### Б14. Рекомендуемая структура JS-файлов

Порядок секций:

1. Импорты
2. Константы
3. Переменные
4. Функции
5. Основной код
6. Экспорты

```js
// Импорты
import { getData } from './api.js';

// Константы
const MAX_COUNT = 5;

// Переменные
const button = document.querySelector('.button');

// Функции
const handleClick = () => {};

// Код программы
button.addEventListener('click', handleClick);

// Экспорты
export { handleClick };
```

### Б17. Приватные и защищенные поля классов

* Приватные поля — `#field`
* Защищенные поля — `_field`

```js

  #password;
  _token;
}
```

Запрещено обращаться к ним извне класса.

# Модульность

```js

```

# Безопасность

### Б36. Обработчики `document` удаляются своевременно

Глобальные обработчики:

* добавляются только при необходимости;
* удаляются после использования.

```js
document.addEventListener('keydown', onEscKeydown);
document.removeEventListener('keydown', onEscKeydown);
```

---

### Б37. Безопасная работа с `innerHTML`

Нельзя вставлять внешние данные в `innerHTML` без экранирования.

```js
import he from 'he';

element.innerHTML = he.encode(user.fullName);
```

Безопаснее использовать:

```js
element.textContent = user.fullName;
```
